# CF VANGUARD STRIDE TO VICTORY TRAD

## INTRO

It's a fan made project, you can read the doc in >> [wiki section](https://github.com/FrogChopi/CF-VANGUARD-STRIDE-TO-VICTORY-FANMADE-TRAD/wiki) <<

This project targets **Cardfight!! Vanguard: Stride to Victory!!** first, but the tooling and reverse-engineering work here is meant to be reused for other FuRyu 3DS titles sharing the same engine, namely:
- Cardfight!! Vanguard: Ride to Victory!!
- Cardfight!! Vanguard: Lock on Victory!!
- Future Card Buddyfight: Appears! Our Strongest Buddy!!
- Future Card Buddyfight: Explosive Fight of Friendship!
